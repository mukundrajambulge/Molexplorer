Stage 1: Foundation Corrections

Week 1–2 · Fix Scientific Accuracy of Existing Features

These are bugs and inaccuracies in code we already have. Must fix before adding new features.

1.1 Hydrogen Bond Detection — Add Angle Criterion

AspectDetails
Current CodeInteractions.ts checks only distance: 2.5Å ≤ d ≤ 3.5Å between N/O/S atoms
ProblemNo angle check. A backbone N near a carbonyl O at 90° is NOT a hydrogen bond — it's a steric contact. This produces massive false positives.
PyMOLUses both distance (≤ 3.2Å D···A) AND angle (≥ 120° D–H···A)
ScienceBaker & Hubbard (1984) DOI: 10.1016/0079-6107(84)90007-5
FixAdd D–H···A angle calculation. If H position unknown, estimate from D–H vector using VSEPR geometry. Require angle ≥ 120°.
ImplementationIn Interactions.ts, after distance check, compute angle using atan2 of cross/dot products between D→H and H→A vectors

1.3 Fix Alignment — Add Iterative Outlier Rejection

AspectDetails
Current CodeAlignment.ts does single-pass Kabsch on all matched Cα pairs
ProblemFlexible loops heavily skew RMSD. PyMOL's align iteratively removes pairs with d > 2σ from the mean
PyMOLalign: 5 cycles of outlier rejection (default cycles=5, cutoff=2.0 sigma)
ScienceKabsch (1976) DOI: 10.1107/S0567739476001873
FixAfter initial Kabsch, compute per-pair distances. Remove pairs where di > d̄ + 2σ. Repeat Kabsch. Iterate 5 times.

1.4 Fix Needleman-Wunsch Scoring Matrix

AspectDetails
Current CodeMatch=1, Mismatch=−1, Gap=−1 (trivial scoring)
ProblemDoesn't account for amino acid similarity. Leu↔Ile substitution should score higher than Leu↔Asp.
FixReplace with BLOSUM62 substitution matrix. Add affine gap penalties (gap open=−10, gap extend=−1).

Stage 3: Measurement & Label System

Week 3–4 · Distance, Angle, Dihedral, Labels

3.1 Distance Measurement

AspectDetails
PyMOLdistance dist1, /mol//A/100/CA, /mol//A/200/CA — draws dashed line with Å label
Scienced = √[(x₂−x₁)² + (y₂−y₁)² + (z₂−z₁)²]
MolStudioNot implemented
ImplementationClick-to-measure mode: user clicks two atoms, draw dashed cylinder + floating Å label. Store in Zustand.

3.2 Angle Measurement

AspectDetails
PyMOLangle ang1, atom1, atom2, atom3 — shows angle arc with degree label
Scienceθ = arccos[(BA⃗ · BC⃗) / (|BA⃗| × |BC⃗|)]
Implementation3-atom click mode. Draw two lines at vertex + arc indicator + degree label.

3.3 Dihedral Measurement

AspectDetails
PyMOLdihedral dih1, a1, a2, a3, a4
Scienceω = atan2(|n₁ × n₂| · b̂₂, n₁ · n₂) where n₁ = b₁ × b₂, n₂ = b₂ × b₃
Implementation4-atom click mode. Already have dihedral() in MolProcessor.ts — expose to UI.

3.4 Label System

AspectDetails
PyMOLlabel n. CA, resn+resi — places text at atom positions
ImplementationUse 3Dmol.js addLabel() API. Support templates: {resn}, {resi}, {chain}, {name}, {elem}, {b}.

Stage 5: Electrostatics & Protein Preparation

Week 6–8 · Poisson-Boltzmann, Gasteiger Charges, Ramachandran

5.1 Electrostatic Surface Potential

AspectDetails
PyMOLutil.protein_vacuum_esp (quick) + APBS plugin (rigorous)
SciencePoisson-Boltzmann: ∇·[ε(r)∇φ(r)] − κ²(r)φ(r) = −4πρ(r)/ε(r)
Baker et al. (2001) DOI: 10.1073/pnas.181342398
MolStudioNot implemented
Phase AVacuum Coulomb ESP: φ(r) = Σ qᵢ / (εᵣ · |r − rᵢ|) with distance-dependent dielectric εᵣ = 4r. Map onto surface as Red(−)/White(0)/Blue(+).
Phase BIntegrate PDB2PQR → APBS via server-side API on Oracle VPS.

5.2 Gasteiger Partial Charges

AspectDetails
ScienceGasteiger & Marsili (1980) DOI: 10.1016/0040-4020(80)80168-2
CurrentDocking.ts hardcodes charge = 0.000 for all protein atoms
FixImplement PEOE iterative algorithm: Δq = (χ_A − χ_B) / (χ_A + χ_B) × damping. 6 iterations.

5.3 Ramachandran Plot

AspectDetails
ScienceRamachandran et al. (1963) DOI: 10.1016/S0022-2836(63)80023-6
ImplementationCompute (φ, ψ) using dihedral() in MolProcessor.ts. Render as 2D scatter plot with allowed regions. Color by SS type. Click → highlight in 3D.
