# Per-Selection Presentation Specification (SQ-UI-01)

## 1. Executive Summary

This document specifies the authoritative architecture, precedence algebra, registry vocabulary, and conflict resolution semantics for per-selection visual overrides in Molexplorer.

Historically, visualization commands and GUI styling tools applied representations and color schemes globally across all atoms in the 3D viewport. The **Per-Selection Presentation Engine** replaces monolithic rendering states with a layered, deterministic composition model:

$$\text{AtomStyle}(a) = \text{AtomColorMap}(a) \ \succ \ \text{SelectionOverride}(a) \ \succ \ \text{ObjectOverride}(a) \ \succ \ \text{GlobalPresentation}$$

---

## 2. Precedence Architecture

The effective presentation state for each atom $a$ is resolved by evaluating four strictly ordered precedence tiers:

```
+-------------------------------------------------------------+
| Tier 4: Most-Specific Atom Overrides / Spectrum Engine      |
|         Per-atom color mapping (e.g. spectrum command)      |
+-------------------------------------------------------------+
                              | (overrides Tier 3)
                              v
+-------------------------------------------------------------+
| Tier 3: Selection Presentation Overrides                    |
|         Scoped to arbitrary atom selections / queries       |
|         Resolution: Chronological Last-Write-Wins (LWW)     |
+-------------------------------------------------------------+
                              | (overrides Tier 2)
                              v
+-------------------------------------------------------------+
| Tier 2: Molecular Object Overrides                          |
|         Scoped to discrete molecular entities (e.g. main_mol)|
+-------------------------------------------------------------+
                              | (overrides Tier 1)
                              v
+-------------------------------------------------------------+
| Tier 1: Global Presentation Base                            |
|         Default viewport style & color scheme               |
+-------------------------------------------------------------+
```

### Precedence Resolution Formal Definition

1. **Tier 1 — Global Base Presentation (`globalRepresentation`, `globalColorScheme`, `globalOpacity`):**
   Provides baseline representation (e.g. `cartoon`), default color scheme (e.g. `Classic CPK`), and base opacity ($0.0 \le \alpha \le 1.0$) for all atoms.
2. **Tier 2 — Object Overrides (`objectOverrides: Map<string, ObjectPresentationState>`):**
   If an atom belongs to a molecular object with explicit representation, color, or visibility overrides, those values take precedence over Tier 1.
3. **Tier 3 — Selection Overrides (`selectionOverrides: Map<string, SelectionPresentationOverride>`):**
   When a command (`show sticks, ligand`, `color cyan, resn HEM`) or GUI interaction modifies a subset of atoms, a `SelectionPresentationOverride` record is generated. If multiple selections overlap on atom $a$, the override with the latest `appliedAt` timestamp wins (Last-Write-Wins).
4. **Tier 4 — Per-Atom Color Map (`atomColorMap: Map<number, string>`):**
   Continuous gradients generated by thermodynamic or electrostatic spectrum engines (e.g. `spectrum bfactor, rainbow`) evaluate at single-atom granularity, overriding discrete selection/object colors while preserving representation styles.

## 3. Authoritative Representation Registry

Molexplorer enforces a strict, closed vocabulary of canonical representation names:

| Canonical Name | PyMOL / Jmol Aliases | Description | 3Dmol Rendering Strategy |
| :--- | :--- | :--- | :--- |
| `lines` | `line`, `wireframe` | Wireframe single-pixel bonds | `{ line: { color, linewidth: 2.0 } }` |
| `sticks` | `stick` | Standard covalent cylinder bonds | `{ stick: { color, radius: 0.22, opacity } }` |
| `spheres` | `sphere`, `spacefill`, `vdw` | Van der Waals space-filling spheres | `{ sphere: { color, radius: 0.65, opacity } }` |
| `ball_and_stick`| `ball-and-stick`, `ballandstick`| High-contrast ball and stick | `{ stick: { radius: 0.15 }, sphere: { radius: 0.35 } }` |
| `cartoon` | `cartoons` | Protein secondary-structure cartoon with directional $\beta$-sheet arrowheads | `{ cartoon: { color, arrows: true, tubes: false } }` |
| `ribbon` | `ribbons` | Flat ribbon spline without arrowheads | `{ cartoon: { color, style: 'ribbon' } }` |
| `trace` | `traces` | Smooth single-line backbone spline | `{ cartoon: { color, style: 'trace' } }` |
| `putty` | `putties` | Variable-radius tube mapped to B-factors | `{ cartoon: { color, tubes: true, thickness: 0.45 } }` |
| `surface` | `surfaces`, `vdw_surface` | Molecular solvent/VDW surface mesh | Surface layer overlay + low-opacity sticks |
| `mesh` | `meshes` | Wireframe solvent surface mesh | Wireframe surface polygon overlay |
| `dots` | `dot`, `dotsurface` | Solvent-accessible dot cloud | `{ dot: { color, radius: 0.35 } }` |
| `nonbonded` | `cross`, `crosses` | Cross representation for ions/solvents | `{ cross: { color, radius: 0.5, linewidth: 1.5 } }` |
| `nb_spheres` | `nbspheres`, `smallspheres` | Reduced-radius spheres for non-bonded atoms | `{ sphere: { color, radius: 0.45, opacity } }` |
| `labels` | `label` | 3D billboard text annotations | Dynamic 3D canvas billboard text overlay |

## 4. Color Resolution Algebra

Colors can be specified as standard named colors, 3/6-digit hex strings, or algorithmic color schemes:

- **Named Colors:** `yellow` (`#eab308`), `cyan` (`#06b6d4`), `green` (`#22c55e`), `forest` (`#15803d`), `lime` (`#84cc16`), `red` (`#ef4444`), `blue` (`#3b82f6`), `deepblue` (`#1d4ed8`), `marine` (`#0284c7`), `orange` (`#f97316`), `magenta` (`#ec4899`), `purple` (`#a855f7`), `violet` (`#8b5cf6`), `pink` (`#ec4899`), `hotpink` (`#f43f5e`), `teal` (`#14b8a6`), `gold` (`#eab308`), `silver` (`#94a3b8`), `white` (`#ffffff`), `black` (`#000000`), `gray`/`grey` (`#64748b`), `carbon` (`#22c55e`).
- **Hex Specifications:** `#RGB` and `#RRGGBB` formats validated via regex `/^#([0-9a-f]{3}|[0-9a-f]{6})$/i`.
- **Schemes:** `Classic CPK`, `Modern/Jmol`, `By Chain`, `Secondary Structure`, `Hydrophobicity`, `ESP Potential`, `B-Factor Putty`, `Rainbow / Spectrum`.

## 5. Scientific Immutability Guarantees

All presentation operations are strictly read-only and guarantee:
1. **$H_{\text{before}} \equiv H_{\text{after}}$**: Canonical molecular hash is identical before and after style changes.
2. **Zero Scientific Revisions**: Display mutations do not record or advance scientific document revisions.
3. **Bit-for-bit Coordinate Preservation**: Atomic Cartesian coordinates $(x, y, z)$, formal charges, valences, and covalent topologies remain unchanged.
